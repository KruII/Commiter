## Interaction Patterns

### Drag and Drop
```
1. Mouse down on widget
   ↓
2. Widget selected (stored in drag_data)
   ↓
3. Mouse move while holding button
   ↓
4. Widget follows cursor
   ↓
5. Mouse up
   ↓
6. Widget stays at new position
   ↓
7. Position saved to layout file
```

### Theme Toggle
```
Click theme button
   ↓
Theme mode toggles (dark ⟷ light)
   ↓
All UI elements update colors
   ↓
All widgets receive new theme
   ↓
Widgets update their colors
```

### Add Widget
```
Click "Add Widget" button
   ↓
Dialog opens with widget types
   ↓
User selects widget type
   ↓
Widget created at default position (50, 50)
   ↓
User drags to desired position
   ↓
Position saved with "Save Layout"
```
